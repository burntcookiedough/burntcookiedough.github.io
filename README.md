# burntcookiedough.github.io

Portfolio of **Anshul Panigrahi**, AI engineer building LLM products and tool-using agents.

Live at **https://burntcookiedough.github.io/**

Hand-built HTML, CSS and JavaScript with no framework and no build step. The scenes (the city, the planet, the hallway and the clouds) are drawn procedurally on canvas.

## Editing

All content lives in [`projects.js`](projects.js): name, role, links, resume URL, projects and milestones. Change it and push; GitHub Pages redeploys automatically.

| File | What it holds |
| --- | --- |
| `index.html` | Page structure |
| `style.css` | Design tokens, layout, responsive rules |
| `main.js` | Scenes, scroll engine, loader |
| `projects.js` | Content |
